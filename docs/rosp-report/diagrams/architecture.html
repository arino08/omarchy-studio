Omarchy Studio — Proposed System Architecture

1. PRESENTATION LAYER (FRONTENDS)

TUI Cockpit (ratatui)Keyboard-driven full-screen app: module rail, live previews, in-terminal images (kitty / sixel / half-blocks), help overlay, command palette, self-theming from the active Omarchy theme
CLI Twin (clap)Every screen has a scriptable verb group — theme, keybind, looknfeel, waybar, monitor, snapshot, rice, doctor… — each mutating command prints its undo hint
Omarchy IntegrationMenu entry (Style → Studio), floating-terminal launch, lifecycle hooks (theme-set, post-update) that survive omarchy-update
⇅ typed requests / typed results — the core never prints, draws or prompts

2. CORE ENGINE (studio-core)

Apply Pipeline (every mutation)
plan→drift check→snapshot (pre)→atomic write→reload→verify→commit | rollback
Risk levels: Safe (instant), Restarty (restarts a component), Risky (10-second confirm-or-revert). A failed verification restores the pre-snapshot, re-runs the reloads and deletes files the apply created.
Domain Modules (31)themes, wallpapers, keybinds, looknfeel, animations, waybar, mako, swayosd, lock/idle, monitors, power, apps, tweaks, rice, shell…
Palette LabMedian-cut extraction (Normal / Muted / Material), HSL + WCAG contrast guard, wallhaven client
⇅ file edits (FileEdit)  ·  reload steps  ·  verifications

3. CONFIG ENGINE (configfs) — LOSSLESS PARSERS & WRITERS

hyprlang Line CSTByte-identical round-trip of Hyprland .conf files (Omarchy 3)
Lua EmitterDeterministic hl.config / hl.monitor / o.bind blocks for Omarchy 4
JSONC Span-SpliceComment-preserving Waybar config edits
TOML (toml_edit)colors.toml, swayosd, Studio config
Managed BlocksMarked regions in CSS / INI / conf; hash-guarded atomic writes
⇅ paths · commands · capability probes

4. OMARCHY ADAPTER & SYSTEM INTERFACES

Omarchy AdapterThe only code allowed to name Omarchy paths; version probe (3.8 / 4.0), component presence
Dialect Probehyprctl systeminfo → hyprlang or Lua config provider
Command RunnerTimeouts, captured output, dry-run; hyprctl, omarchy-theme-set, omarchy-restart-*
Desktop ComponentsHyprland, Waybar / omarchy-shell, mako, SwayOSD, hypridle, pacman, power-profiles-daemon
External ServicesGitHub releases & community themes, wallhaven.cc JSON API
⇅ read / write

5. PERSISTENCE LAYER

Snapshot Store (git repository)~/.local/state/omarchy-studio/history — mirrored copies of every managed file, manifest.toml, genesis / pre / post / drift / restore commits
User Configuration Files~/.config/hypr, waybar, mako template, swayosd, omarchy/themes — user-owned surfaces only
Studio Config & Cache~/.config/omarchy-studio/config.toml, thumbnail & preview caches
